## 数据模型

单个课程对象:
- id: 时间戳ID ("c_1693000000000")
- name: 课程名 / location: 教室 / teacher: 教师
- dayOfWeek: 1-7 (周一到周日)
- startPeriod/endPeriod: 开始/结束节次
- startTime/endTime: 时间字符串 "HH:MM"
- weekType: "all"|"odd"|"even"
- colorIndex: 0-7

Storage keys: schedule_courses / schedule_settings / schedule_version

## 页面设计

### 1. 今日视图 (index) - 默认首页
- 顶部：日期 + 第X周 + 当前课程状态
- 中部：今日课程列表，当前课程高亮边框
- 底部：倒计时距下节课/距当前课结束
- 交互：左右滑动切换日期，底部按钮跳转周视图
- 导航：点击课程->详情页; "+"->添加课程; "周"按钮->周视图

### 2. 周视图 (week)
- 布局：纵向表格，左列节次(1-10)，右方7列(周一~周日)
- 内容：每格显示课程名缩写，背景色区分
- 交互：点击格子->详情页; 当前节次行高亮

### 3. 添加/编辑课程 (add-course)
- 表单：课程名(input text)、教室、教师
- 选择器：星期(picker-view)、开始/结束节次(picker-view)
- 单双周：3个radio (全部/单周/双周)
- 颜色：8色横向色块 click选择
- 编辑模式：通过路由参数courseId判断

### 4. 课程详情 (detail)
- 展示：课程名、教室、教师、时间、周次、颜色
- 操作：编辑按钮->add-course编辑模式、删除按钮(确认后删除)

## JS heap 风险评估

| 资源 | 估算 | 说明 |
|------|------|------|
| 课程数据(20门) | ~4KB | JSON+解析对象 |
| 页面data | ~2KB | 当前页数据 |
| 常量/工具函数 | ~3KB | 节次表+颜色+工具 |
| 框架/路由 | ~20KB | 估算 |
| 常驻总计 | ~31KB | 远低于512KB |
| 峰值(页面切换) | ~50KB | 旧+新页面共存 |

## Assumptions

1. 学期起始日默认2026-09-01
2. 节次时间表使用通用大学10节次，不支持自定义
3. 单双周基于学期起始日自然周次
4. 颜色固定8色不支持自定义
5. 手机同步本期不实现
6. 振动仅分钟级short振动
7. 删除确认使用页面内覆盖层(Lite Wearable无dialog组件)
8. CSS按336x396像素布局
9. 课程数据建议不超过50门
10. picker-view range必须字符串数组
