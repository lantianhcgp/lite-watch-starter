## 怎么用（CI / 布局 / 资源）

1. **build-profile 的 SDK 版本上限**：`compatibleSdkVersion`/`targetSdkVersion` 不得超过
   目标机型的「最高 compatible / target」。
   - API10+ 档（GT4/5/6、FIT3/4、D2、Runner2、Ultimate…）→ 本仓实测可用
     `compatibleSdkVersion "4.0.0(10)"`（elcton 仓 FIT3 装表成功 profile）；
   - GT3 系（API7?）、GT2 系（compatible API3!）、FIT2/D（API7）是老档，
     `4.0.0(10)` 会装不上——需按官方 SDK 版本表换算更低版本串（未在本仓验证）。
   - **SDK 新 ≠ 能装**：编译可高（compileSdk 6.1.1(24)），兼容声明必须 ≤ 机型档位。
2. **布局基准用适配分辨率**（圆表 336×306、方表 336×396、D 276×360），不是物理分辨率；
   超出即被裁。圆表另有内接矩形计算器（表尾 desmos 链接）。
3. **js heap 决定资源预算**：GT2 系 64K 是全表最低基线，GT3 256K（Pro 才 512K），
   FIT2/FIT3 512K；未知机型按 64K 兜底。单 js 页面 >48KB 直接报安装错误 34。
4. 代号/固件列用于记录实测环境（装表问题复现要报「代号+固件」，不只营销型号）。

同源浓缩版（heap 档位 / 分辨率分组 / API 观察 + 审慎规则）见 skill
`huawei-lite-watch-development/references/device-compatibility.md`。
